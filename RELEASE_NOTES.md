## Performance v0.1.0

Initial Windows x64 desktop build.

Includes a GamerLoop-inspired dark glass dashboard, live hardware telemetry, game-session island, PresentMon FPS sampling, process manager, TCP connection inspector, installed-app uninstaller handoff, residual-folder review, and manual storage scanner.

Run as Administrator when temperature sensors or PresentMon frame capture are unavailable without elevation. Borderless fullscreen is recommended for the in-game overlay.
